# Дух методолога

Telegram-бот, который отвечает по материалам вашего проекта и помогает учиться
на реальных задачах. Внутри нет зашитого курса: замените Markdown-файлы в
`memory/` и `skills/`, перезапустите бота — получите наставника для своей
команды, курса или pet project.

Ответы генерирует GPT-5 через [Polza.ai](https://polza.ai). Бот работает через
Telegram long polling, поэтому для первого запуска не нужны домен, HTTPS и
webhook.

## Что уже умеет

- отвечает по банку знаний проекта;
- учитывает методический скилл, а не просто пересказывает документацию;
- помнит последние сообщения диалога в локальной SQLite;
- работает в личке и в группах;
- перечитывает изменённые файлы командой `/reload`;
- ограничивает доступ списком Telegram ID;
- запускается обычным Python-процессом или в Docker.

## Быстрый запуск

Нужны Python 3.11+ и два токена: Telegram и Polza.ai.

```bash
git clone https://github.com/lebed52/methodologist-bot.git
cd methodologist-bot

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
```

Заполните `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=токен_из_BotFather
POLZA_AI_API_KEY=ключ_из_Polza.ai
POLZA_AI_MODEL=openai/gpt-5
```

Запуск:

```bash
python -m src.bot
```

Откройте своего бота в Telegram, нажмите Start и отправьте вопрос.

## Создание бота через BotFather

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Задайте отображаемое имя. Например: `Дух методолога`.
4. Задайте username, который заканчивается на `bot`. Например:
   `my_project_methodologist_bot`.
5. Скопируйте токен в `TELEGRAM_BOT_TOKEN`.
6. Выполните `/setdescription` и добавьте короткое описание.

Не публикуйте токен и не добавляйте `.env` в Git. Если токен утёк, откройте
`/revoke` в BotFather и выпустите новый.

### Работа в группе

Добавьте бота в группу как обычного участника. Он отвечает только когда:

- его упомянули через `@username`;
- пользователь ответил reply на сообщение бота.

Такой режим работает с включённым Privacy Mode. Отключать его через
`/setprivacy` не требуется.

## Ключ Polza.ai

1. Зарегистрируйтесь на [Polza.ai](https://polza.ai).
2. Создайте API-ключ в личном кабинете.
3. Положите ключ в `POLZA_AI_API_KEY`.
4. Оставьте `POLZA_AI_BASE_URL=https://api.polza.ai/v1`.
5. Для этого шаблона модель по умолчанию — `openai/gpt-5`.

Если модель недоступна вашему аккаунту, укажите другой доступный ID в
`POLZA_AI_MODEL`. Код использует OpenAI-compatible Chat Completions API.

## Как подставить свой проект

В `memory/` лежат демонстрационные файлы. Удалите их или перепишите:

```text
memory/
├── project.md         # устройство проекта и запуск
├── learning-path.md   # порядок обучения
└── faq.md             # частые вопросы команды
```

Можно добавить сколько угодно вложенных `.md`-файлов. Хорошо работают:

- архитектура и словарь терминов;
- команды локального запуска;
- ссылки на внутренние разделы;
- примеры задач и критерии готовности;
- типичные ошибки;
- правила code review;
- программа обучения.

В `skills/` лежат четыре готовых режима: общая методика, объяснение, практика и
разбор ошибок. Это обычные Markdown-файлы — удаляйте ненужные, добавляйте свои и
адаптируйте правила под аудиторию.

После изменения файлов выполните в Telegram:

```text
/reload
```

Бот перечитает банк без перезапуска процесса.

### Чего не класть в память

Не добавляйте `.env`, пароли, API-ключи, персональные данные и закрытые документы,
которые нельзя отправлять внешней модели. Содержимое выбранных файлов уходит в
Polza.ai вместе с вопросом пользователя.

## Команды

- `/start` и `/help` — краткая инструкция;
- `/new` — удалить историю текущего чата;
- `/reload` — перечитать `memory/` и `skills/`;
- `/status` — показать модель, число документов и режим доступа.

## Ограничение доступа

По умолчанию написать боту может любой пользователь, который знает его username.
Для закрытого бота заполните:

```dotenv
ALLOWED_USER_IDS=123456789,987654321
```

Узнать свой numeric ID можно через Telegram-ботов вроде `@userinfobot`. Не
добавляйте их в рабочие закрытые группы.

## Docker

```bash
cp .env.example .env
# заполните .env
docker compose up -d --build
docker compose logs -f
```

Папки `memory/` и `skills/` монтируются read-only, база истории хранится в
`data/`. После правки Markdown достаточно команды `/reload`.

## Как это устроено

```text
Telegram
   ↓
src/bot.py          команды, группы, длинные ответы
   ↓
src/knowledge.py    выбор релевантных Markdown-файлов
   ↓
src/ai.py           GPT-5 через Polza.ai
   ↓
src/storage.py      история чатов в SQLite
```

Это намеренно простой стартовый шаблон. Здесь нет vector database, админки и
облачной БД. Для небольшого курса или команды Markdown хватает; когда банк
вырастет настолько, что перестанет помещаться в контекст, следующий шаг —
embeddings и поиск по фрагментам.
