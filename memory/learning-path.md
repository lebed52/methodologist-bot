# Учебный маршрут

Замените пример своей программой обучения.

## Этап 1. Познакомиться с проектом

- понять назначение продукта и его пользователей;
- запустить проект локально;
- найти основные директории и точки входа;
- выполнить первый безопасный запрос к API.

## Этап 2. Выполнить задачу с подсказками

- выбрать небольшую реальную задачу;
- составить план;
- выполнить работу по шагам;
- проверить результат;
- объяснить, почему решение работает.

## Этап 3. Самостоятельная практика

- решить похожую задачу без готовой инструкции;
- провести самопроверку;
- разобрать ошибки;
- записать новое знание в банк памяти.
